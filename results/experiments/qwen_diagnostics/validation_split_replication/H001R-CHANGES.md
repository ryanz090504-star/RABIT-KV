# H001 → H001R: relabel record (2026-10-23)

**Why:** `validation-split-audit/AUDIT.md` found no recorded use of the WikiText-2 validation split, but could not rule out prior use. So the run must not be called held-out, unseen-input or confirmatory validation.

**What changed:** only labels and claims. The inputs, windows, token pools, arms, controls, anchors, models, thresholds, bootstrap settings and analysis arithmetic are unchanged. Offline gates prove this (see below).

**What was preserved:** the H001 preparation was never published, pushed or launched. All 46 of its files were moved, byte-verified, into `superseded-H001/`, and `superseded-H001/snapshot-sha256.json` lists their hashes. The local image `runpod-qwen-h001:local` (`sha256:371818f1…`) was left in Docker untouched.

**Exact diffs:** `h001r-relabel.diff` covers 17 files and is generated with `git diff --no-index superseded-H001/<f> <f>`. The edits were made by count-checked string replacements in the five `tools/` builders, followed by a rebuild. No generated file was hand-edited except `PROTOCOL.md`.
